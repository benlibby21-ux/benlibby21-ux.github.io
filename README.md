# Ben Libby | Selected Work

Static portfolio site. All original project copy and links are preserved.

## GitHub Pages publishing

1. Create a **public** repository named `benlibby21-ux.github.io` under the `benlibby21-ux` GitHub account.
2. Upload `index.html` to the repository root and commit it to the `main` branch.
3. In repository Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
4. Visit https://benlibby21-ux.github.io/ after Pages finishes deploying.

This does not modify your existing ChatGPT Sites custom domain DNS settings.
